# Tools & Plugins - Blockbench Plugin

Since it is not yet available in the official Blockbench plugin store, you will need to install it manually.

You can find the plugin in [Universal Emotes Toolkit](https://github.com/theptah/universal-emotes-toolkit) repository.

## Installation

1. Open the **Blockbench** desktop app or access the web version at [web.blockbench.net](https://web.blockbench.net/).
2. In the top menu, go to **File** > **Plugins** (or press `Ctrl + Shift + P`).
3. Click the **Load Plugin from URL** icon (the link icon next to the search bar).
4. Paste the raw URL of the plugin file into the field and confirm.
